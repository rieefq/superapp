## UI KIT — shared rules
- Location: src/ui/** ; public API via src/ui/index.ts (barrel). Presentational: props-driven; may import types from @/core/types and helpers from @/lib; must NOT import db/services EXCEPT the "connected primitives" explicitly listed for the display agent.
- Styling: Tailwind v4 utilities bound to the design tokens in src/styles/tokens.css (semantic utility names defined via @theme — e.g. bg-surface-1, text-ink-2, border-line, text-accent…). Never raw hex/rgb values or arbitrary font families in components. Use `cn()` from @/lib/cn. Variants via small typed maps (no CVA dependency).
- Accessibility: correct roles/ARIA, focus-visible ring token, keyboard support (Enter/Space/Arrows/Escape/Home/End/typeahead where applicable), labels on icon-only buttons, color never the only signal, reduced-motion respected (CSS `@media (prefers-reduced-motion)` + `html[data-motion="reduce"]`).
- Motion: `motion/react` only where it adds meaning (overlays enter/exit, layout transitions, live indicators); durations/easings from tokens.
- Every component: typed props (extend native element props where sensible, forwardRef/ref-as-prop per React 19), sensible defaults, `className` passthrough.
- A living gallery route (owned by the kit agents): src/ui/gallery/** rendered at /dev/ui (wire it as a route-less lazy page: export a component the orchestrator will route) showing every component in all variants/states, in both themes (toggle). Used for visual QA screenshots.

## A1 — PRIMITIVES, FORMS, OVERLAYS, LAYOUT, HOOKS
- Button (variants: primary | secondary | ghost | outline | danger | link; sizes xs | sm | md | lg; leading/trailing icon (LucideIcon), loading, kbd hint, fullWidth); ButtonLink (react-router Link styled as Button).
- IconButton (icon, label → aria-label + Tooltip, sizes, variants, active/pressed state).
- Input, Textarea (autosize option), SearchField (icon, clear, kbd hint), Field (label, hint, error, required, htmlFor wiring), Select (custom listbox: options with icon/description/disabled, keyboard nav, typeahead, controlled), Checkbox, Switch, RadioGroup, SegmentedControl, Slider, NumberInput (optional).
- Tabs (underline + pill variants; controlled/uncontrolled; roving tabindex; optional counts), Breadcrumbs.
- Menu / DropdownMenu (trigger, items with icon/shortcut/description, separators, labels, checkable items, danger items, submenu optional; keyboard nav, typeahead, Escape, click-outside, returns focus), ContextMenu (right-click wrapper using the same menu).
- Popover (anchored floating panel with flip/shift positioning — implement a small positioning utility; portal; focus management), Tooltip (hover/focus, delay ~400ms, aria-describedby), HoverCard (delayed preview on hover/focus).
- Dialog (modal; focus trap; Escape; sizes sm/md/lg/xl/full; header/body/footer slots; initial focus), Sheet (side drawer left/right/bottom, mobile bottom sheet; same a11y), confirm() imperative API → Promise<boolean> (title, description, confirmLabel, tone 'danger', optional typed confirmation) + <ConfirmHost/>, toast() imperative API (success/error/info/warning/loading; title, description, action {label, onClick} or link, duration, dismiss; promise helper) + <ToastHost/>.
- Badge (tones: neutral/accent/success/warning/danger/info; subtle/solid/outline), Tag/Chip (removable, selectable), Kbd (and KbdCombo "⌘ K"), Avatar (initials + hue; image optional), Spinner, Skeleton (text/rect/circle), ProgressBar (determinate/indeterminate; tones), Divider, VisuallyHidden.
- Surface/Card (elevation levels per spec; interactive variant with hover/focus), Panel (header/body/footer), SectionHeader, PageHeader (workspace header pattern: eyebrow, title, description, actions, tabs slot), Toolbar, EmptyState (icon/illustration, title in display face, description, actions; compact variant), ErrorState (message, retry), ListItem / NavItem primitives (icon, label, meta, trailing, active), DynamicIcon (string lucide name → component from a curated map of ~120 icons used by data: project/collection/capability/kind icons), SplitPane (two resizable panes with keyboard-accessible drag handle, min/max, persisted size by id; collapsible side), ScrollArea (styled native scroll container).
- Hooks: useHotkey(combo | combo[], handler, {enabled, allowInInputs}), useChord (two-key sequences like "g c"), useDisclosure, useClickOutside, useMediaQuery + useBreakpoint ('sm'|'md'|'lg'|'xl'), useLocalStorageState, useReducedMotion (combines OS + settings.appearance.reduceMotion), useCopy (clipboard with copied state), useDebounced.
- Theme application: ThemeProvider/useTheme that applies `data-theme` on <html> from settings.appearance.theme (system → follows prefers-color-scheme live), `data-density`, `data-motion`. (This is the ONE place A1 may read settings: import useSettings from @/core/settings.)

## A2 — DATA DISPLAY, SIGNATURE COMPONENTS, CHARTS (+ connected primitives)
- Markdown (react-markdown + remark-gfm; typography per spec; code fences → CodeBlock; tables styled + horizontally scrollable; links: internal paths → router Link, external → new tab with rel; citation markers `[n]` turned into CitationMarker when a `citations` prop is passed (click/hover reveals the source); `streaming` prop shows a caret at the end; safe — no raw HTML).
- CodeBlock (sugar-high highlighting with token colors from the theme; language label; copy; optional line numbers + highlighted lines; max-height with expand; wrap toggle), InlineCode.
- DiffView (from `diff` package: unified and split modes; hunk headers; old/new line numbers; context collapsing with "expand"; add/remove backgrounds per tokens; word-level emphasis optional; large-file guard; header slot for file path, stats and review actions), DiffStat (+12 −3 bar).
- Terminal / LogView (monospace output; light ANSI-like coloring heuristics for PASS/FAIL/✓/✗/error/warn lines; streaming autoscroll that stops when the user scrolls up; copy; command line display with prompt glyph; "simulated output" label slot).
- RunTimeline (props: run: Run, onApprove/onReject?, renderRef?) — vertical step list: kind icon, title, detail, status indicator (live pulse when running; waiting = approval tone), timing (duration or elapsed live), expandable body: input (command/query), output (Terminal for command/test, list for search, Markdown for message), refs as entity chips, file changes summary (DiffStat per file); inline ApprovalCard for waiting steps; a "next step…" skeleton row while running. RunStatusBadge, StepIcon, RunMeta (RUN code · model · tokens · cost (estimate when simulated) · duration).
- ApprovalCard (compact + full; title, requester identity, risk badge, capability label/icon, reason, preview (command → Terminal-styled, diff → DiffView, message → quoted message with destination label), optional note field, Approve / Reject actions with loading, resolved state with who/when/note).
- AgentMark (procedural identity sigil from seed + hue — distinctive geometric mark, 16-64px, optional live ring/pulse when working; NOT a robot avatar), LiveIndicator / Pulse (the single consistent "AI is working" motion motif; tones), StatusDot.
- MetaLabel (mono uppercase metadata), IdCode (RUN-4F2A), SimBadge ("Simulated" with explanatory tooltip) and LiveBadge ("Live"), ProvenanceLine (presentational: model label, simulated flag, tokens, cost, duration).
- Stat (metric tile: label, value, unit, delta with direction semantics, optional sparkline, helper text), Meter (value vs max with threshold tones).
- Charts (inline SVG, responsive via ResizeObserver, themed via tokens, following the dataviz references): Sparkline, TimeSeriesChart (line/area, multi-series, stacked option, x time axis, y axis with nice ticks, hover crosshair + tooltip, legend for ≥2 series), BarChart (vertical/horizontal, grouped/stacked, hover tooltip), DonutChart (with center label; ≤6 slices else "Other"), Heatmap (weekday × hour or calendar grid with sequential ramp + tooltip), ChartLegend, chart table fallback (visually hidden table or toggle).
- ProceduralArt: renders AssetPreview {type:'procedural', seed, palette, style} as rich, beautiful generative SVG (styles: photographic → soft layered gradients/blur-like blobs + grain; illustration → flat shapes and bold forms; 3d → shaded spheres/extrusions with light falloff; abstract → geometric composition; editorial → large type-like blocks + texture), deterministic per seed, any aspect ratio; plus `exportArtSvg(spec, w, h)` and `exportArtPng(...)` helpers for real downloads.
- FileIcon (by extension), Tree (generic keyboard-navigable tree view: expand/collapse, selection, lazy children, filter highlight) — used by the repo explorer.
- DataTable (columns config, sortable headers, sticky header, row click/keyboard, empty state, dense option, pagination helper).
- ActivityFeed (ActivityEvent[] → actor mark/avatar, summary, relative time, target chip; grouped by day).
- Connected primitives (may import from @/core/services/entities and @/core/services/approvals): EntityChip (icon + title + kind; hover card preview with subtitle/status/updated; click → navigate to entityRoute; removable variant; compact variant), EntityHoverCard, EntityIcon (kind → icon), CitationMarker.
